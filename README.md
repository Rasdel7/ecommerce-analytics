# E-Commerce Analytics Dashboard 🛒

Complete online shopping analytics platform
covering sales, customers, products and operations.

## Live Demo
[Click here](https://ecommerce-analytics-rdwaikff28aykxruk5pjra.streamlit.app)

## Features
- 6 analytics tabs: Overview, Trends, Products,
  Customers, Operations, Profitability
- 2000 orders across 8 categories, 11 cities
- Customer segmentation (Bronze/Silver/Gold/Platinum)
- RFM-style customer analysis
- Delivery time vs rating correlation
- Profit margin by category
- Payment method breakdown

## Key Insights
- Beauty has highest profit margins (55%)
- UPI is most popular payment method (45%)
- Mumbai and Delhi drive most revenue
- Electronics highest revenue, lowest margin

## Tools Used
- Python, Streamlit, Plotly, Pandas

## How to Run Locally
pip install streamlit pandas numpy plotly
streamlit run app.py
